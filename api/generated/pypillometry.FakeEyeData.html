class pypillometry.FakeEyeData(time, left_x=None, left_y=None, left_pupil=None, right_x=None, right_y=None, right_pupil=None, sim_fct=None, sim_fct_name=None, sim_params=None, sim_data=None, **kwargs)[source]#

Bases: EyeData

EyeData with simulation metadata for testing and validation.

Extends EyeData with four attributes:

  • sim_fct: Reference to the function used to generate this data

  • sim_fct_name: Name of the generation function (str)

  • sim_params: Dictionary with generation parameters (excludes function reference)

  • sim_data: EyeDataDict with ground truth time series (one value per sample; cut, decimated and filled in together with the data)

This class enables:

  1. Printing how the data was generated via get_generation_call()

  2. Regenerating data with the same or modified parameters via regenerate()

  3. Accessing ground truth for validation

classmethod from_eyelink(fname, return_edf_obj=False, remove_eyelink_triggers=True, **kwargs)#

Reads an eyedata object from an Eyelink file.

All “messages” are stored as events (can be filtered later) and it tries to be smart to detect different information from the EDF file. Spatial calibration/validation data is automatically parsed and stored in the calibration attribute as SpatialCalibration objects. Eyelink codes missing pupil samples (e.g., during blinks) as 0; these are converted to NaN (and therefore masked).

However, the EDF file may contain other information of interest, e.g., eyelink-detected saccades, etc. If you need more control, use the “eyelinkio” package directly and create the object manually.

Reading EDF files is slow (about a minute for a 90 MB file). Save the object with write_file() and read it with from_file() later, or convert the files once with the command-line program edf2pypil.

Parameters:

  • fname (str) – filename of the EDF file, HTTP(S) URL or SSH URL (ssh://server/folder/file.edf, see pypillometry.io.fetch_url())

  • return_edf_obj (bool) – if True, return a tuple with the eyedata object and the object returned by the “eyelinkio” package; if False (default), return only the eyedata object

  • remove_eyelink_triggers (bool) – if True (default), remove all Eyelink triggers from the events (related to eye-tracker settings, calibration, validation etc)

  • **kwargs – additional arguments passed to pypillometry.io.read_eyelink() (e.g., cache_file, cache_dir, cache_layout, autodelete, session)

Return type:

EyeData or tuple

Returns:

object of the class this method is called on (e.g., EyeData), or tuple with that object and the object returned by the “eyelinkio” package

Examples

>>> import pypillometry as pp
>>> d = pp.EyeData.from_eyelink('data.edf')
>>> # Access calibration data
>>> print(d.calibration['left'])
<SpatialCalibration: left eye, HV9, n=9, error=0.45±0.23° (max=0.79°)>

add_events(events, inplace=None)#

Add events to the events of the dataset.

The new events are merged with the existing ones and all events are sorted by onset (events at the same time keep their order, existing ones first). Metadata columns that only the existing or only the new events have get missing values (NaN or “”) for the other events. Events from a behaviour log on another clock must be mapped to the eye-tracker clock with sync_clocks() first; a warning is given for events that are marked as being on another clock (needs_sync, e.g., from from_table()).

Parameters:

  • events (Events) – the events to add (converted to ms if needed)

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the object with the added events (self or a copy, depending on inplace)

Raises:

  • TypeError – if events is not an Events object

  • ValueError – if an onset is outside the time range of the data

See also

set_events

replace all events

Examples

Events from a behaviour log behav (a table with times in sec, already on the eye-tracker clock; otherwise, see sync_clocks()):

>>> ev = pp.Events.from_table(behav, ["stim_on", "response"], units="sec",
...                           needs_sync=False)
>>> d = d.add_events(ev)

downsample(fsd, dsfac=False, policy='default', inplace=None)#

Simple downsampling scheme using mean within the downsampling window.

All data fields and the time-vector are downsampled simultaneously. See pypillometry.signal.baseline.downsample(). The samples that are unusable under the mask policy are left out of the window means (by default, interpolated samples are used, see mask()). A layer is kept for a new sample if it covers more than half of its window. A new sample whose window has no usable sample holds the mean of the stored values (NaN only if they are NaN) and stays unusable.

The new sampling rate is fs/factor, the rate of the decimated data. It differs from fsd if fs/fsd is not an integer (e.g., 1000 Hz with fsd=300 gives factor 3 and 333.3 Hz).

Parameters:

  • fsd (float) – new sampling-rate (in Hz) or decimate-factor

  • dsfac (bool) – if False (default), fsd is the requested sampling rate (the decimate factor is int(fs/fsd); a warning is logged if fs/fsd is not an integer); if True, fsd is the decimate factor (a positive integer)

  • policy (str, MaskPolicy or list of str) – mask policy that decides which samples are used for the window means (see mask()); default "default"

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the downsampled object (self or a copy, depending on inplace)

Raises:

  • TypeError – if fsd is not a number

  • ValueError – if the sampling rate fsd is not above 0 and at most fs, or the decimate factor is not a positive integer

drop_data(eyes=[], variables=[], inplace=None)#

Drop specified eyes and/or variables from the data.

All data of the given eyes and all data of the given variables are dropped (together with their mask layers). Everything else is kept (events, excluded periods, parameters, history, experimental setup, calibration); the class of the object does not change.

Parameters:

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the object without the specified data (self or a copy, depending on inplace)

Raises:

  • KeyError – If an eye or variable does not exist.

  • ValueError – If dropping would result in no data remaining.

Examples

>>> import pypillometry as pp
>>> d = pp.get_example_data("rlmw_002_short")
>>> # Drop left eye data
>>> right_only = d.drop_data(eyes=["left"], inplace=False)
>>> right_only.eyes
['right']

>>> gaze_only = d.drop_data(variables=["pupil"], inplace=False)
>>> # Drop right eye and pupil data
>>> left_gaze = d.drop_data(eyes=["right"], variables=["pupil"], inplace=False)
>>> sorted(left_gaze.data.keys())
['left_x', 'left_y']

exclude_intervals(intervals, inplace=None)#

Exclude periods that are not part of the analysis (e.g., breaks or the calibration at the start).

The periods are stored with the object as the recording-wide "excluded" layer (see get_excluded()), which masks all variables (also those added later), so that functions that ignore masked data (e.g., scale(), get_segments()) also ignore the excluded periods. Unlike other masked data (blinks, artifacts), excluded periods are not treated as missing data: blink detection cuts blinks at them, and blinks that end in an excluded period are not interpolated. Blinks detected before keep their layer.

The layer moves with the samples (crop(), downsample(), remove_intervals(), …). Calling the method again adds to the excluded periods; clear_layer("excluded") removes them.

Parameters:

  • intervals (Intervals, Epochs or list of tuple) – the periods to exclude: an Intervals object (e.g., from get_intervals(); in time units or sample indices), Epochs or a list of (start, end) tuples (in ms, or with units, e.g., [(0, 2 * u.min)]; "<start>" and "<end>" stand for the start and end of the recording, e.g., [(10 * u.min, "<end>")]); ends are exclusive

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the object with the excluded periods (self or a copy, depending on inplace)

See also

keep_intervals

exclude everything outside the given periods

Examples

>>> breaks = d.get_intervals(start="break_start", end="break_end", units="ms")
>>> d = d.exclude_intervals(breaks)
>>> d = d.exclude_intervals([(0, 2 * u.min)])

fill_time_discontinuities(yval=nan, print_info=True, inplace=None)#

Find gaps in the time-vector and fill them in.

A gap is a step between consecutive time points that is larger than twice the median step. New time points are inserted into each gap at the median step size and all data variables are set to yval at these new time points; they are masked as missing. Existing masks are kept and stored blinks (in sample indices) are moved to the new sample positions. This is called by the constructor when fill_time_discontinuities=True.

Parameters:

  • yval (float, optional) – value used for the data in the filled-in gaps; default NaN, so the filled-in samples are masked as missing data (other values: masked by the "user" layer)

  • print_info (bool, optional) – if True (default), log the number of gaps that are filled in

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the object without gaps (self or a copy, depending on inplace)

get_epochs(event_select, window, units=UNSET, label=None, exact=False, **kwargs)#

Return the time windows around events (Epochs).

Selects events, e.g., all stimuli, and one time window around each of them, e.g., from 200 ms before to 1000 ms after the stimulus. The result is the input of get_segments() (event-related pupil dilations) and can be used wherever intervals are taken (e.g., stat_per_event(), mask_intervals()). For spans between two different events (e.g., from trial start to response), use get_intervals().

Parameters:

  • event_select (str, function or Events) –

    which events to select:

    • str: all events whose label contains the string (or is equal to it, if exact is True); "<start>" and "<end>" stand for the start and the end of the recording

    • function: applied to all labels, the events where it returns True are used

    • Events: the events of this Events object (e.g., d.events.filter(cond="easy"))

  • window (tuple (min, max) or Quantity) – time window relative to the event onset (0 is the onset; negative numbers are before it), e.g. (-200, 800) * u.ms or ("-0.2 sec", "0.8 sec"). Plain numbers are in units.

  • units (str) – units of plain numbers in window (“ms”, “sec”, “min”, “h”, or “samples” for sample indices, converted to ms with the sampling rate); default: the units of window, or “ms” for plain numbers

  • label (str | None) – label of the Epochs; if None, it is taken from event_select

  • exact (bool) – if True, a string selector matches only labels that are equal to it; if False (default), labels that contain it

  • **kwargs – passed on to the event_select function; an error is raised if it is not a function

Return type:

Epochs

Returns:

the selected events (onsets in ms, labels and metadata, see Events) and the window (in ms). Windows that extend beyond the data are not clipped.

Examples

>>> import pypillometry as pp
>>> from pypillometry import u
>>> d = pp.EyeData(time=range(10000), left_pupil=range(10000),
...                event_onsets=[2000, 6000], event_labels=["stim", "stim"])
>>> d.get_epochs("stim", (-200, 800) * u.ms)
Epochs 'stim' | 2 epochs, window (-200, 800) ms

get_interpolated(eyes=[], variables=[], units='ms')#

  • end (str or function) –

    the events at the start and at the end of the spans:

    • str: all events whose label contains the string (or is equal to it, if exact is True); "<start>" and "<end>" stand for the start and the end of the recording (the first sample and one sample past the last one, as intervals are end-exclusive)

interpolate_intervals(intervals, eyes=[], variables=[], method='linear', margin=(-20, 20), store_as_suffix=None, policy='default', inplace=None)#

Interpolate data within specified intervals.

This function replaces data within the specified intervals with interpolated values based on boundary points outside each interval. The interpolated samples get the "interpolated" layer (see get_interpolated()), so they are used under the default mask policy and masked under the "strict" one (see mask()). Intervals without usable boundary points on both sides are skipped with a warning.

Parameters:

  • intervals (Intervals, Epochs, list of tuple or dict) –

    Either:

    • A single Intervals (or Epochs) object or a list of (start, end) tuples (in ms, or with units): applied to all specified eyes/variables

    • A dict of Intervals (or Epochs): keys like “left_pupil”, “right_x”, etc. When dict is provided, eyes and variables are ignored.

  • eyes (str or list of str, optional) – eye(s) to interpolate; if empty, all available eyes. Ignored if intervals is a dict.

  • variables (str or list of str, optional) – variable(s) to interpolate; if empty, all available variables. Ignored if intervals is a dict.

  • method (str, default "linear") – Interpolation method. Options: “linear”, “nearest”, “zero”, “slinear”, “quadratic”, “cubic”, “previous”, “next”. Passed to scipy.interpolate.interp1d.

  • margin (tuple, default (-20, 20)) – Time window (in ms) before and after the interval to collect boundary points for interpolation, relative to the start and end of each interval: points are taken from start + margin[0] to the start and from the end to end + margin[1], so margin[0] must be <= 0 and margin[1] >= 0. Samples that are unusable under policy (masked or NaN) are not used. For higher-order methods like “cubic” or “quadratic”, more boundary points from this margin are used to fit the interpolation curve.

  • store_as_suffix (str or None, default None) – If None, replace the original data. If a string, store interpolated data in a new variable with this suffix (e.g., “_interp” creates “left_pupil_interp”).

  • policy (str, MaskPolicy or list of str) – mask policy that decides which boundary points are usable (see mask()); default "default"

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

remove_intervals(intervals, inplace=None)#

Remove the data in the given periods (e.g., breaks) and join the rest.

The samples in the periods are deleted. Gaps between the remaining data are closed: the data after a removed period are shifted back in time, so that they continue where the removed period started (the time vector has no gap). Removing data at the beginning or end does not change the times, so removing everything before start and after end is the same as crop(). Event onsets are shifted with the data; events within removed periods are deleted. Stored blinks and excluded periods are moved to the new positions. The removed periods are added to params["removed_intervals"], in the original time (the time before any periods were removed; a period across a gap closed by an earlier call is split at the gap). params["removed_shifts"] holds the shifts between the current and the original time.

To remove the periods marked with exclude_intervals(), use d.remove_intervals(d.get_excluded()).

Filters or interpolation applied after joining treat the data on both sides of a removed period as neighbors; apply them before, or use split_excluded() to process the parts separately.

Parameters:

  • "percent": mean and mean / 100, so the result is the change in % of the mean (for a percent change relative to a baseline before each event, see SegmentedEyeData.pupil.baseline_correct)

Parameters:

  • variables (str or list of str, optional) – variables to scale; can be “pupil”, “x”,”y”, “baseline”, “response” or any other variable that is available in the dataset; either a string or a list of strings; available variables can be checked with obj.variables; empty list means all variables

  • method (str) – how center and scale are computed if they are None: "z" (default), "robust", "minmax" or "percent" (see above)

  • center (Union[float, dict, None]) – value to subtract; if None, computed with method; a number (same for all eyes and variables) or one per channel as {"left_pupil": value, ...}

  • scale (Union[float, dict, None]) – value to divide by; if None, computed with method; a number or one per channel as {"left_pupil": value, ...}

  • eyes (str or list of str, optional) – eye(s) to consider; if empty, all available eyes

  • policy (str, MaskPolicy or list of str) – mask policy that decides which samples are used for center and scale (see mask()); default "default" (interpolated samples are used)

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

EyeData

Returns:

the scaled object (self or a copy, depending on inplace)

Raises:

ValueError – if method is unknown, or scale is 0 or not finite for a channel (e.g., a constant signal, or a MAD of 0)

Notes

The scaling parameters are stored in params["scale"] ({"center": {"left_pupil": ...}, "scale": {...}, "method": {...}}) and used by unscale(). Scaling a variable again combines the parameters, so that unscale() restores the values before the first scale.

Examples

>>> import pypillometry as pp
>>> d = pp.get_example_data("rlmw_002_short")
>>> z = d.scale("pupil", inplace=False)                     # z-scores
>>> r = d.scale("pupil", method="robust", inplace=False)    # units of the MAD
>>> p = d.scale("pupil", method="minmax", inplace=False)
>>> bool(p["left_pupil"].min() == 0 and p["left_pupil"].max() == 1)
True
