GazePlotter#

class pypillometry.GazePlotter(obj)[source]#

Bases: GenericPlotter

Class for plotting gaze data. The class is initialized with a GenericEyeData object and provides methods to plot the data in various ways.

It is usually not created directly; instead, it is available as the plot attribute of a GazeData object, e.g. d.plot.plot_heatmap().

Parameters:

obj (GenericEyeData) – the data object to plot (stored as obj)

plot_calibration(eyes=None, show_surface=True, interpolation='rbf', figsize=(10, 8))[source]#

Plot spatial calibration data for one or more eyes in subplots.

Creates a figure with subplots for each eye and calls the plot() method on each SpatialCalibration object to show calibration accuracy with target points (black X), measured points (dark blue +), and optional interpolated error surface.

Parameters:

  • eyes (Union[str, list, None]) – Which eye(s) to plot. If None or empty list, plots all available eyes. Can be a single eye name (e.g., ‘left’) or list of eye names (e.g., [‘left’, ‘right’]).

  • show_surface (bool) – If True, show interpolated error surface as background. If False, show only the calibration points.

  • interpolation (str) – Interpolation method for surface (only used if show_surface=True). Options: ‘rbf’, ‘linear’, ‘cubic’, ‘nearest’

  • figsize (tuple) – Figure size per subplot (width, height) in inches.

Returns:

  • fig (matplotlib.figure.Figure) – The figure object

  • axes (list or matplotlib.axes.Axes) – List of axis objects (or single axis if only one eye)

Raises:

ValueError – If no calibration data is available

Examples

>>> import pypillometry as pp
>>> data = pp.EyeData.from_eyelink('data.edf')
>>> # Plot all eyes with surface
>>> fig, axes = data.plot.plot_calibration()
>>> 
>>> # Plot only left eye without surface
>>> fig, ax = data.plot.plot_calibration(eyes='left', show_surface=False)
>>> 
>>> # Plot specific eyes
>>> fig, axes = data.plot.plot_calibration(eyes=['left', 'right'])
plot_heatmap(plot_range=(-inf, inf), eyes=[], show_screen=True, show_masked=False, rois=None, roi_style={}, units='sec', cmap='jet', gridsize=30, min_samples=1, smooth=None, limits=None)[source]#

Plot EyeData as a heatmap. Typically used for a large amount of data to spot the most frequent locations. To plot a scanpath, use plot_scanpath() instead. Each eye is plotted in a separate subplot of the current figure (a new figure is created if none exists); the colorbar shows the number of samples per bin.

Parameters:

  • plot_range (tuple) – The time range to plot (in units, or with units, e.g. (3, 5) * u.min). Default is (-np.inf, +np.inf), i.e. all data.

  • eyes (list) – The eyes to plot. Default is [], which means all available data (“left”, “right”, average, regression, …)

  • show_screen (bool) – Whether to plot the screen limits (if an experimental setup is available). Default is True.

  • show_masked (bool) – Whether to plot the masked data (because of blinks, artifacts, …). Default is False.

  • rois (List[ROI]) – List of ROIs (ROI) to plot. Default is None.

  • roi_style (dict) –

    Style for the ROIs, passed as keyword arguments to the ROIs’ plot() method. Default is {} (ROI defaults). Example:

    {
    "facecolor": "red",
    "edgecolor": "black",
    "linewidth": 2,
    "alpha": 0.5
}

  • units (str) – The units of plot_range (“ms”, “sec”, “min”, “h”). Default is “sec”.

  • cmap (str) – The colormap to use. Default is “jet”.

  • gridsize (int | str) – The gridsize for the hexbin plot or histogram. If “auto”, the square root of the number of samples in plot_range is used. Default is 30.

  • min_samples (Optional[int]) – Minimum number of samples required in a bin to display it. Bins with fewer samples will not be shown. If None, automatically calculates a threshold at the 10th percentile of bin counts. Default is 1.

  • smooth (Optional[float]) – If provided, applies Gaussian smoothing to the binned histogram. The value is the sigma of the Gaussian kernel in bin units (e.g., smooth=1 applies minimal smoothing with a 1-bin sigma, smooth=2 applies more smoothing). When smooth is provided, uses a rectangular grid instead of hexbin.

  • limits (Optional[Tuple[float, float, float, float]]) – Axis limits as (xmin, xmax, ymin, ymax). If not provided, uses screen limits when available (and data falls within), otherwise uses data extent.

Raises:

ValueError – if plot_range does not overlap with the data

Return type:

None

Examples

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> d.plot.plot_heatmap(eyes="left")
plot_intervals(intervals, eyes=[], variables=[], pdf_file=None, nrow=5, ncol=3, figsize=(10, 10), show_mask=False, show_index=True)#

Plotting data around intervals.

Intervals can be extracted with get_intervals(). Each interval gets a separate subplot. The data is plotted for each eye and variable in different colors. The x-axis is plotted in the units of the Intervals object. If the intervals contain event onsets, these are marked by a dashed red line.

Parameters:

  • intervals (Intervals) – Intervals object containing the intervals to plot (from get_intervals())

  • eyes (str | list) – eyes to plot; if empty, all available eyes are plotted

  • variables (str | list) – variables to plot; if empty, all available variables are plotted

  • pdf_file (Optional[str]) – if the name of a file is given, the figures are saved into a multi-page PDF file (missing directories are created)

  • nrow (int) – number of rows for the subplots for the intervals

  • ncol (int) – number of columns for the subplots for the intervals

  • figsize (Tuple[int, int]) – size (width, height) of each figure in inches

  • show_mask (bool) – shade samples masked in any of the plotted eyes/variables

  • show_index (bool) – plot a number with the interval’s index (e.g., for identifying abnormal blinks)

Return type:

list of matplotlib.figure.Figure

Returns:

one figure per nrow x ncol intervals (also returned when pdf_file is given; the figures are then closed)

Raises:

TypeError – if intervals is not an Intervals object

Examples

The pupil around each stimulus, one panel per interval:

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> intervals = d.get_intervals("S_", (-500, 2500) * u.ms)
>>> d.plot.plot_intervals(intervals, variables="pupil", nrow=2, ncol=5,
...                       figsize=(12, 4))
plot_masked(eyes=[], variables=[], units='min', merge=False, show_labels=True, show_events=False, **kwargs)#

Plot masked intervals for specified eyes and variables.

Visualizes masked data segments as horizontal lines on a timeline, similar to Intervals.plot(). Each interval is shown at a different y-level. When plotting multiple eyes/variables without merging, each is shown in a different color with slight y-offsets for clarity.

Parameters:

  • eyes (str | list) – Eye(s) to plot masks for. If empty, uses all available eyes.

  • variables (str | list) – Variable(s) to plot masks for. If empty, uses all available variables.

  • units (str) – Time units for x-axis: “ms”, “sec”, “min”, “h”, or None for indices. Default is “min”.

  • merge (bool) – If True, merge all masks into a single set of intervals for plotting. If False, plot each eye/variable separately with different colors. Default is False.

  • show_labels (bool) – Whether to show labels for each interval group. Default is True.

  • show_events (bool) – Whether to show vertical grey stripes at event positions. Default is False.

  • **kwargs (dict) – Additional keyword arguments passed to matplotlib plot()

Return type:

None

Returns:

Modifies the current axes in place

Examples

One line per masked interval (here: detected blinks) and eye:

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> d.pupil_blinks_detect(apply_mask=True)
>>> plt.figure(figsize=(8, 4))
>>> d.plot.plot_masked(variables="pupil", units="sec")

With merge=True, the masks of all eyes and variables are combined; show_events=True adds the event markers.

plot_scanpath(plot_range=(-inf, inf), eyes=[], show_screen=True, rois=None, roi_style={}, show_onsets=True, title='', units=None, figsize=(10, 10))[source]#

Plot EyeData as a scanpath. Typically used for single trials or another small amount of data. To plot a larger amount of data, use plot_heatmap() instead.

If several eyes are available, they are plotted in the same figure in different colors. You can choose between them using the eyes parameter. The samples are drawn as dots colored by time. A new figure is created for the plot.

Parameters:

  • plot_range (tuple) – The time range to plot (in units, or with units, e.g. (3, 5) * u.min). Default is (-np.inf, +np.inf), i.e. all data.

  • eyes (list) – The eyes to plot. Default is [], which means all available data (“left”, “right”, average, regression, …)

  • show_screen (bool) – Whether to plot the screen limits (if an experimental setup is available). Default is True.

  • rois (List[ROI]) – List of ROIs (ROI) to plot. Default is None.

  • roi_style (dict) –

    Style for the ROIs, passed as keyword arguments to the ROIs’ plot() method. Default is {} (ROI defaults). Example:

    {
    "facecolor": "red",
    "edgecolor": "black",
    "linewidth": 2,
    "alpha": 0.5
}

  • show_onsets (bool) – Whether to plot the event labels at the gaze position at event onset. Plotted only for the first eye. Default is True.

  • title (str) – The title of the plot. Default is “”.

  • units (str) – The units of plot_range (“ms”, “sec”, “min”, “h”). If None (default), the units of the time vector (ms) are used.

  • figsize (tuple) – The figure size (width, height) in inches. Default is (10,10).

Raises:

ValueError – if plot_range does not overlap with the data

Return type:

None

Examples

Two seconds of gaze of the left eye:

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> d.plot.plot_scanpath(plot_range=(10, 12) * u.sec, eyes="left")
plot_timeseries(plot_range=(-inf, inf), variables=[], eyes=[], units=None, show_onsets='line', show_masked=True, show_mask_highlight=True, label_prefix='', style=None)#

Plot a part of the EyeData. Each data type is plotted in a separate subplot.

Uses the current figure/axes. If no figure exists, creates one automatically.

Parameters:

  • plot_range (tuple) – The time range to plot (in units). Default is (-np.inf, +np.inf), i.e. all data.

  • variables (list) – The data to plot. Default is [], which means all available data will be plotted. Available data are [“x”,”y”,”pupil”] but can be extended by the user.

  • eyes (list) – The eyes to plot. Default is [], which means all available data (“left”, “right”, “average”, “regression”, …)

  • units (Optional[str]) – The units of plot_range and the time axis (“ms”, “sec”, “min”, “h”). If None (default), use the units in the time vector (ms).

  • show_onsets (str) – Whether to plot markers for the event onsets. One of “line” (vertical lines), “label” (text label), “both” (both lines and labels), or “none” (no markers). Default is “line”.

  • show_masked (bool) – Whether to plot the data in masked regions. If True (default), plots all data including masked regions. If False, masked data points are not plotted (gaps in the line).

  • show_mask_highlight (bool) – Whether to highlight masked regions with a light red background. Default is True.

  • label_prefix (str) – Prefix to add to labels in the legend. Useful for overlaying multiple datasets. Default is “” (no prefix).

  • style (dict) –

    Styling for plotted lines. Can be:

    • Single dict: Applied to all eyes with automatic differentiation (e.g., {‘color’: ‘red’})

    • Dict of dicts: Per-eye styling (e.g., {‘left’: {‘linestyle’: ‘-‘}, ‘right’: {‘linestyle’: ‘–‘}})

    Default is None (uses matplotlib defaults with automatic per-eye colors and linestyles).

Raises:

ValueError – if show_onsets is not one of the allowed values or if plot_range does not overlap with the data

Return type:

None

Examples

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> plt.figure(figsize=(10, 6))
>>> d.plot.plot_timeseries(plot_range=(0, 20) * u.sec, units="sec")
plot_timeseries_segments(pdf_file=None, interv=1, figsize=(15, 5), ylim=None, eyes=[], variables=[], units='min', **kwargs)#

Plot the whole dataset chunked up into segments (usually to a PDF file).

Parameters:

  • pdf_file (str) – file name to store the PDF; if None, no PDF is written

  • interv (float) – duration of each of the segments to be plotted (in the units specified by units)

  • figsize (Tuple[int,int]) – dimensions of the figures

  • ylim (Tuple[float,float] or None) – y-axis limits for all subplots

  • eyes (list) – list of eyes to plot; if empty, all available eyes are plotted

  • variables (list) – list of variables to plot; if empty, all available variables are plotted

  • units (str) – units for the time axis; default is “min” (minutes). The interv parameter is also interpreted in these units.

  • **kwargs – additional arguments passed to plot_timeseries()

Return type:

list of matplotlib.figure.Figure or None

Returns:

one figure per segment; None if pdf_file is given

Examples

Split the 40-second recording into 10-second pieces (one figure each, here only the first is shown):

>>> import pypillometry as pp
>>> from pypillometry import u
>>> import matplotlib.pyplot as plt
>>> d = pp.get_example_data("rlmw_002_short")
>>> figs = d.plot.plot_timeseries_segments(interv=10, units="sec",
...                                        variables="pupil", figsize=(10, 3))
>>> for f in figs[1:]:
...     plt.close(f)

With pdf_file="segments.pdf", the figures are written to a PDF file instead.
