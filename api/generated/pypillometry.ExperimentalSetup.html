ExperimentalSetup#

class pypillometry.ExperimentalSetup(screen_resolution=None, physical_screen_size=None, screen_offset=None, eye_to_screen_center=None, screen_pitch=None, screen_yaw=None, camera_offset=None, camera_spherical=None, ipd=None)[source]#

Bases: Stateful

Complete geometric model of an eye-tracking experimental setup.

Encapsulates:

  • Screen geometry (resolution, physical size)

  • Eye position relative to screen (perpendicular distance and offset)

  • Screen orientation (pitch and yaw tilt angles)

  • Camera position (relative to screen or eye)

  • Inter-pupillary distance (for binocular setups)

Provides:

  • Coordinate conversion between pixels and mm

  • Transformation from screen coordinates to eye-centered 3D frame

  • Validation of parameter consistency

  • Visualization of the setup geometry

  • Serialization for saving/loading

All parameters are optional; an incomplete setup can be created and used for whatever is set (accessing a missing value raises ValueError). Lengths and angles can be given as plain numbers, as strings with units (e.g., "52 cm", "-5 deg") or with a unit (e.g., 52 * pp.u.cm). Plain numbers are interpreted as mm (lengths) or radians (angles), with a one-time warning.

Parameters:

  • screen_resolution (Optional[Tuple[int, int]]) – Screen resolution in pixels (width, height).

  • physical_screen_size (Optional[Tuple[Union[float, str], Union[float, str]]]) – Physical screen dimensions (width, height); each element a length (default unit mm), e.g., ("52 cm", "29 cm").

  • screen_offset (Optional[Tuple[Union[float, str], Union[float, str]]]) – Offset of screen center from the eye reference point (delta_x, delta_y); each element a length (default unit mm). Default (0, 0). Positive delta_x = screen center is to the right of eye. Positive delta_y = screen center is above eye. Note: For binocular setups, the reference is the midpoint between the two eyes (root of nose).

  • eye_to_screen_center (Union[float, str, None]) – Distance from eye to screen center (default unit mm), e.g., "65 cm". The perpendicular distance d between eye and screen plane is computed from d = sqrt(eye_to_screen_center**2 - delta_x**2 - delta_y**2). If screen_offset is (0, 0) or not set, d equals eye_to_screen_center. Raises ValueError if it is smaller than the screen offset. Note: For binocular setups, “eye” refers to the midpoint between the two eyes (root of nose).

  • screen_pitch (Union[float, str, None]) – Screen pitch angle (alpha_tilt; default unit radians), e.g., "-5 deg". Rotation about horizontal axis. Positive = top of screen tilted away from eye. Default 0.

  • screen_yaw (Union[float, str, None]) – Screen yaw angle (beta_tilt; default unit radians), e.g., "3 deg". Rotation about vertical axis. Positive = right side of screen closer to eye. Default 0.

  • camera_offset (Optional[Tuple[Union[float, str], Union[float, str], Union[float, str]]]) – Camera position as (x, y, z) offset from eye; each element a length (default unit mm). z-axis points toward screen center. Takes precedence over camera_spherical if both are given.

  • camera_spherical (Optional[Tuple[Union[float, str], Union[float, str], Union[float, str]]]) – Alternative: camera position in spherical coordinates (theta, phi, r) relative to eye: theta is the polar angle from the z-axis and phi the azimuthal angle in the x-y plane (angles, default unit radians); r is the distance from eye (length, default unit mm).

  • ipd (Union[float, str, None]) – Inter-pupillary distance for binocular setups (default unit mm), e.g., "63 mm".

Notes

All coordinates are in an eye-centric reference frame where:

  • The origin is at the eye position

  • For binocular setups, this is the midpoint between the two eyes (root of nose)

  • z-axis points toward the screen center

  • x-axis points to the right

  • y-axis points upward

Examples

>>> # Basic setup with distance to screen center
>>> setup = ExperimentalSetup(
...     screen_resolution=(1920, 1080),
...     physical_screen_size=("52 cm", "29 cm"),
...     eye_to_screen_center="65 cm",
...     camera_offset=("0 cm", "-30 cm", "0 cm"),  # camera below screen
... )
>>> print(f"d = {setup.d} mm")
d = 650.0 mm

>>> # Setup with screen offset and tilt
>>> setup = ExperimentalSetup(
...     screen_resolution=(1920, 1080),
...     physical_screen_size=("52 cm", "29 cm"),
...     eye_to_screen_center="65 cm",
...     screen_offset=("3 cm", "-1.5 cm"),  # screen right and below eye
...     screen_pitch="-5 deg",  # screen tilted back
...     camera_offset=("0 cm", "-30 cm", "0 cm"),
... )

>>> # Visualize the setup
>>> fig, axes = setup.plot()

Notes

mm_to_degrees(x_mm, y_mm)[source]#

Convert mm coordinates (relative to screen center) to visual angles.

Parameters:

  • x_mm (Union[float, ndarray]) – Coordinates in mm relative to screen center. Positive x = right, positive y = up.

  • y_mm (Union[float, ndarray]) – Coordinates in mm relative to screen center. Positive x = right, positive y = up.

Return type:

Tuple[Union[float, ndarray], Union[float, ndarray]]

Returns:

angle_x, angle_y (float or array) – Visual angles in degrees. Positive x = right, positive y = up.

Notes

Computes angle = arctan(distance / d) separately for x and y, where d is the perpendicular eye-to-screen distance. This assumes the eye is opposite the screen center; screen_offset and screen tilt are not taken into account.

plot(theta=None, phi=None, projection='2d', show_gaze_samples=True, n_gaze_samples=9, ax=None, viewing_angle=None)[source]#

Visualize the experimental setup geometry.

Parameters:

  • theta (float) – Camera polar angle in radians (plain number only). If None, uses setup’s theta. The camera distance is always taken from the setup (0 if no camera position is set).

  • phi (float) – Camera azimuthal angle in radians (plain number only). If None, uses setup’s phi.

  • projection (str) –

    Type of projection (case-insensitive):

    • ’2d’: Three orthogonal 2D views (front, top, side)

    • ’3d’: Interactive 3D view

  • show_gaze_samples (bool) – Whether to show sample gaze vectors to screen

  • n_gaze_samples (int) – Number of sample gaze positions; drawn as a square grid with int(sqrt(n_gaze_samples)) points per side.

  • ax (matplotlib Axes, optional) – Existing 3D axis to plot on (only for ‘3d’ projection; ignored for ‘2d’, which always creates a new figure).

  • viewing_angle (tuple) – Viewing angle for 3D projection (elev, azim) or (elev, azim, roll) in degrees. Default is (-49, 50, 45) for 3D.

Returns:

  • fig (matplotlib.figure.Figure) – The figure.

  • ax (matplotlib.axes.Axes or numpy.ndarray) – The 3D axis for ‘3d’; an array of the three axes (front, top, side) for ‘2d’.

Raises:

ValueError – If screen info or eye-to-screen distance is not set, if theta or phi is None and no camera position is set, or if projection is not ‘2d’ or ‘3d’.

Examples

>>> import pypillometry as pp
>>> import matplotlib.pyplot as plt
>>> setup = pp.ExperimentalSetup(
...     screen_resolution=(1920, 1080),
...     physical_screen_size=("52 cm", "29 cm"),
...     eye_to_screen_center="60 cm",
...     camera_spherical=("20 deg", "-90 deg", "70 cm"),
... )
>>> fig, ax = setup.plot()  # 2D views
>>> fig, ax = setup.plot(projection='3d')  # 3D view
screen_point_to_eye_frame(x_mm, y_mm)[source]#

Transform screen point(s) from screen-centered mm to eye-centered 3D frame.

Applies screen tilt rotation and eye offset translation.

Parameters:

  • x_mm (Union[float, ndarray]) – Screen coordinates in mm (relative to screen center)

  • y_mm (Union[float, ndarray]) – Screen coordinates in mm (relative to screen center)

Return type:

Tuple[Union[float, ndarray], Union[float, ndarray], Union[float, ndarray]]

Returns:

T_x, T_y, T_z (float or array) – 3D coordinates in eye-centered frame (mm)

Notes

Uses the transformation from algorithm document Section 10.7.3: T(x_s, y_s) = R(alpha, beta) @ [x_s, y_s, 0]^T + [delta_x, delta_y, d]^T, i.e., the screen center is at (delta_x, delta_y, d) for any tilt.
