GroupLevelSegmentedData#

class pypillometry.GroupLevelSegmentedData(name, variable, tx, data, mask_percent, n_subjects, intervals=None, sampling_rate=None)[source]#

Bases: SegmentedEyeData

Group-level segmented eye data combining multiple subjects.

This class inherits from SegmentedEyeData and adds group-level functionality. It combines multiple SegmentedEyeData objects (one per subject) into a single group-level object, either by stacking or aggregating.

Usually created with group_segments() (or from_segments()) from a list or dict of SegmentedEyeData objects, one per subject.

The data keep their mask: stacked segments keep their own mask, and in aggregate mode a subject’s mean is masked where all of their segments are masked. In addition, mask_percent stores the average percentage of masked trials per subject at each timepoint.

Parameters:

  • name (str) – Name of the dataset

  • variable (str) – Variable name in “eye_variable” format

  • tx (ndarray) – Time axis relative to segment onset (in ms)

  • data (MaskedArray) – Masked array with shape (n_timepoints, n_subjects) or (n_timepoints, n_segments)

  • mask_percent (ndarray) – Percentage of masked data per subject at each timepoint (shape: n_timepoints)

  • n_subjects (int) – Number of subjects combined

  • intervals (Intervals, optional) – Source Intervals object

  • sampling_rate (float) – Original sampling rate in Hz

classmethod from_segments(segments, meanfct=<function mean>, name=None)[source]#

Create GroupLevelSegmentedData by combining multiple SegmentedEyeData objects.

Parameters:

  • segments (list) – List of SegmentedEyeData objects (one per subject)

  • meanfct (callable or None) – Function to aggregate within each subject, called as meanfct(data, axis=1); it must accept an axis argument and ignore masked values (e.g., np.mean or np.ma.median, but not np.median; a warning is logged otherwise). If None, all segments from all subjects are stacked (concatenated).

  • name (str) – Name for the group-level dataset. If None, uses "group_" + first segment’s name

Return type:

GroupLevelSegmentedData

Returns:

New instance with combined data

Examples

>>> # Aggregate within subjects, then combine
>>> group = GroupLevelSegmentedData.from_segments([subj1, subj2, subj3])

>>> # Stack all trials from all subjects
>>> group = GroupLevelSegmentedData.from_segments([subj1, subj2, subj3], meanfct=None)
baseline_correct(window=0)#

Apply baseline correction to the segments.

The window is specified in milliseconds relative to the zero-point of the intervals (typically the event onset). For example, window=(-200, 0) uses the 200ms before the event as baseline.

Parameters:

window (Union[Tuple[float, float], float, None]) –

Baseline window in ms relative to event onset (time 0):

  • If None, no baseline correction is applied

  • If tuple (start, end), the mean value in this time window is subtracted

  • If float, the value at the time point closest to this value is used

Default is 0 (baseline at event onset).

Return type:

SegmentedEyeData

Returns:

New instance with baseline-corrected data (the object itself if window is None)

Examples

>>> # Use pre-event period as baseline
>>> segments_bc = segments.baseline_correct(window=(-200, 0))

>>> # Use single time point as baseline
>>> segments_bc = segments.baseline_correct(window=-100)
plot(meanfct=<function mean>, varfct=<function sem>, show_missing=None, show_zero_line=True, show_legend=None, title=None, label=None, ribbon_alpha=0.3, ax=None, **kwargs)[source]#

Plot grand mean and error ribbons.

Overrides SegmentedEyeData.plot() to use mask_percent for the missing-data display. Mean and error are computed across the columns of data (subjects when aggregated, all segments when stacked).

Parameters:

  • meanfct (callable) – Function to compute mean across columns (default: np.mean)

  • varfct (callable or None) – Function to compute error bands (e.g., np.std, scipy.stats.sem; default: scipy.stats.sem). If None, no error bands are plotted. Both functions are called as fct(data, axis=1), so they must accept an axis argument, and they must ignore masked values (e.g., np.ma.median, not np.median; a warning is logged otherwise).

  • show_missing (bool) – Plot mask_percent (average percentage of missing data per subject) on secondary y-axis. If None, defaults to True in standalone mode, False in overlay mode.

  • show_zero_line (bool) – Show vertical line at time 0 (default: True)

  • show_legend (bool) – Show legend. If None, only shows legend in standalone mode (ax=None)

  • title (str) – Plot title. If None and ax is None, uses the dataset name. Ignored when ax is provided (for overlay use).

  • label (str) – Label for legend. If None, uses self.name

  • ribbon_alpha (float) – Alpha (transparency) for error ribbon (default: 0.3)

  • ax (matplotlib.axes.Axes, optional) – Axes to plot on. If None, uses current axes (standalone mode)

  • **kwargs (dict) – Additional arguments passed to ax.plot() (e.g., color, linestyle, linewidth)

Returns:

ax (matplotlib.axes.Axes) – The axes object for further customization
