PupilData#

class pypillometry.PupilData(time=None, left_pupil=None, right_pupil=None, event_onsets=None, event_labels=None, sampling_rate=None, name=None, fill_time_discontinuities=True, keep_orig=False, info=None, inplace=None)[source]#

Bases: GenericEyeData

Class representing pupillometric data.

The class is a subclass of GenericEyeData and inherits all its methods.

If eye-tracking data is available in addition to pupillometry, use the EyeData class.

Properties such as eyes and variables are inherited from GenericEyeData.

Parameters:

  • time (ndarray) – timing array (in ms) or None, in which case the time-array goes from [0,maxT] using sampling_rate

  • left_pupil (ndarray) – data from left eye (at least one of the eyes must be provided)

  • right_pupil (ndarray) – data from right eye (at least one of the eyes must be provided)

  • event_onsets (ndarray) – time-onsets of any events in the data (in ms, matched in time vector)

  • event_labels (ndarray) – for each event in event_onsets, provide a label

  • sampling_rate (float) – sampling-rate of the signal in Hz; if None, it is estimated from the median difference in time (either time or sampling_rate must be provided)

  • name (str) – name of the dataset or None (in which case a random string is selected)

  • fill_time_discontinuities (bool) – sometimes, when the eyetracker loses signal, no entry in the EDF is made; when this option is True, such entries will be made and the signal set to 0 there (or do it later using fill_time_discontinuities())

  • keep_orig (bool) – keep a copy of the original dataset? If True, a copy of the object as initiated in the constructor is stored in member original

  • info (dict) – optional dictionary with additional information about the dataset (stored in member info)

  • inplace (Optional[bool]) – default for methods called with inplace=None: if True, they modify the object in place; if False, they return a modified copy; if None (default), use the package-level setting (see set_default_inplace(), initially True). The method-level inplace argument overrides this.

classmethod from_eyelink(fname, return_edf_obj=False, remove_eyelink_triggers=True, **kwargs)#

Reads an eyedata object from an Eyelink file.

All “messages” are stored as event_labels (can be filtered later) and it tries to be smart to detect different information from the EDF file. Spatial calibration/validation data is automatically parsed and stored in the calibration attribute as SpatialCalibration objects. Eyelink codes missing pupil samples (e.g., during blinks) as 0; these are converted to NaN (and therefore masked).

However, the EDF file may contain other information of interest, e.g., eyelink-detected saccades, etc. If you need more control, use the “eyelinkio” package directly and create the object manually.

Parameters:

  • fname (str) – filename of the EDF file, HTTP(S) URL or SSH URL (ssh://server/folder/file.edf, see pypillometry.io.fetch_url())

  • return_edf_obj (bool) – if True, return a tuple with the eyedata object and the object returned by the “eyelinkio” package; if False (default), return only the eyedata object

  • remove_eyelink_triggers (bool) – if True (default), remove all Eyelink triggers from the event_labels (related to eye-tracker settings, calibration, validation etc)

  • **kwargs – additional arguments passed to pypillometry.io.read_eyelink() (e.g., cache_file, cache_dir, cache_layout, autodelete, session)

Return type:

GenericEyeData or tuple

Returns:

object of the class this method is called on (e.g., EyeData), or tuple with that object and the object returned by the “eyelinkio” package

Examples

>>> import pypillometry as pp
>>> d = pp.EyeData.from_eyelink('data.edf')
>>> # Access calibration data
>>> print(d.calibration['left'])
<SpatialCalibration: left eye, HV9, n=9, error=0.45±0.23° (max=0.79°)>

downsample(fsd, dsfac=False, inplace=None)#

Simple downsampling scheme using mean within the downsampling window.

All data fields and the time-vector are downsampled simultaneously. See pypillometry.signal.baseline.downsample(). Masked samples are left out of the window means; a new sample is masked only if all samples in its window were masked. Stored blinks (in sample indices) are rescaled to the new sampling rate.

Parameters:

  • fsd (float) – new sampling-rate (in Hz) or decimate-factor

  • dsfac (bool) – if False (default), fsd is the new sampling rate (the decimate factor is int(fs/fsd)); if True, fsd is the decimate factor

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

GenericEyeData

Returns:

the downsampled object (self or a copy, depending on inplace)

drop_data(eyes=[], variables=[])#

Drop specified eyes and/or variables from the data and return a new object.

This method never works in place - it always returns a new object. All data of the given eyes and all data of the given variables are dropped (together with their stored blinks). The returned object’s class is determined by what data remains:

  • If only pupil variables remain: returns PupilData

  • If only x/y variables remain: returns GazeData

  • If both pupil and x/y remain: returns EyeData

Parameters:

  • eyes (list) – Eyes to drop (e.g., [‘left’] or [‘right’] or [‘left’, ‘right’]); if empty, no eye is dropped

  • variables (list) – Variables to drop (e.g., [‘pupil’] or [‘x’, ‘y’]); if empty, no variable is dropped

Return type:

GenericEyeData subclass

Returns:

A new object with the specified data removed, cast to the appropriate class.

Raises:

ValueError – If dropping would result in no data remaining.

Examples

>>> # Drop left eye data
>>> right_only = data.drop_data(eyes=['left'])
>>> 
>>> # Drop pupil data, keep only gaze
>>> gaze_only = data.drop_data(variables=['pupil'])
>>> 
>>> # Drop right eye and pupil data
>>> left_gaze = data.drop_data(eyes=['right'], variables=['pupil'])

fill_time_discontinuities(yval=nan, print_info=True)#

Find gaps in the time-vector and fill them in (in-place).

A gap is a step between consecutive time points that is larger than twice the median step. New time points are inserted into each gap at the median step size and all data variables are set to yval at these new time points; they are masked as missing. Existing masks are kept and stored blinks (in sample indices) are moved to the new sample positions. This is called by the constructor when fill_time_discontinuities=True.

Parameters:

  • yval (float, optional) – value used for the data in the filled-in gaps; default NaN, so the filled-in samples are masked as missing data

  • print_info (bool, optional) – if True (default), log the number of gaps that are filled in

Return type:

GenericEyeData

Returns:

the object itself (always modified in-place)

get_intervals(event_select, interval=(-200, 200), units=UNSET, label=None, **kwargs)#

Return an Intervals object containing intervals relative to event-onsets. For example, extract the interval before and after a stimulus has been presented. It is possible to select based on the event label, e.g. only select events matching “stimulus” or “response”. It is also possible to select the intervals situated between two different events, e.g., trial start and response by specifying event_select as a tuple with two entries.

Parameters:

  • event_select (str, tuple, function, or Events) –

    variable describing which events to select and align to

    • if str: use all events whose label contains the string

    • if function: apply function to all labels, use those where the function returns True

    • if tuple: use the intervals between the events selected by the first and the second entry (each a str or function); interval[0] is added to the first and interval[1] to the second event (so interval=(0, 0) gives exactly the span between them). Both selectors must result in identical number of events; events are paired by order (n-th first with n-th second event) and a ValueError is raised if a second event comes before its first event.

    • if Events: use the events from the Events object directly

  • interval (tuple) – time-window relative to event-onset (0 is event-onset); i.e., negative numbers are before the event, positive numbers after, e.g. (-200, 800) * u.ms or ("-0.2 sec", "0.8 sec"). Plain numbers are in units given by the units parameter. Default (-200, 200).

  • units (str | None) – units of the returned intervals (one of “ms”, “sec”, “min”, “h”, or None for sampling units, i.e., indices into the time-array); plain numbers in interval are in these units, an interval with units is converted to them. If not given, the units of interval are used (sampling units if interval has no units).

  • label (str | None) – optional label for the Intervals object. If None, a label is automatically generated from the event_select parameter

  • **kwargs – passed onto the event_select function

Return type:

Intervals

Returns:

Intervals object containing interval on- and offsets for each match, with associated metadata (event labels, indices, units)

interpolate_intervals(intervals, eyes=[], variables=[], method='linear', margin=(-20, 20), store_as_suffix=None, inplace=None)#

Interpolate data within specified intervals.

This function replaces data within the specified intervals with interpolated values based on boundary points outside each interval. The interpolated samples are also marked as masked. Intervals without valid (non-NaN) boundary points on both sides are skipped with a warning.

Parameters:

  • intervals (Intervals or dict) –

    Either:

    • A single Intervals object: applied to all specified eyes/variables

    • A dict of Intervals: keys like “left_pupil”, “right_x”, etc. When dict is provided, eyes and variables are ignored.

  • eyes (str or list of str, optional) – eye(s) to interpolate; if empty, all available eyes. Ignored if intervals is a dict.

  • variables (str or list of str, optional) – variable(s) to interpolate; if empty, all available variables. Ignored if intervals is a dict.

  • method (str, default "linear") – Interpolation method. Options: “linear”, “nearest”, “zero”, “slinear”, “quadratic”, “cubic”, “previous”, “next”. Passed to scipy.interpolate.interp1d.

  • margin (tuple, default (-20, 20)) – Time window (in ms) before and after the interval to collect boundary points for interpolation, relative to the start and end of each interval: points are taken from start + margin[0] to the start and from the end to end + margin[1], so margin[0] must be <= 0 and margin[1] >= 0. Masked or NaN samples are not used. For higher-order methods like “cubic” or “quadratic”, more boundary points from this margin are used to fit the interpolation curve.

  • store_as_suffix (str or None, default None) – If None, replace the original data. If a string, store interpolated data in a new variable with this suffix (e.g., “_interp” creates “left_pupil_interp”).

  • inplace (bool or None, optional) – if True, make change in-place and return the object; if False, make and return copy before making changes; if None, use the object-level setting (specified in the constructor)

Return type:

GenericEyeData

Returns:

The object with interpolated data (self or a copy, depending on inplace).

See also

mask_intervals

Apply intervals as masks without interpolation

get_blinks

Retrieve stored blink intervals

Examples

Interpolate blinks for left eye pupil data:

>>> blinks = data.get_blinks(eyes='left', variables='pupil')
>>> data.interpolate_intervals(blinks, eyes=['left'], variables=['pupil'])

Interpolate using a dict of intervals:

>>> blinks = data.get_blinks()  # returns dict
>>> data.interpolate_intervals(blinks)

Store interpolated data in a new variable:

>>> data.interpolate_intervals(blinks, store_as_suffix="_interp")
>>> # Access via data['left', 'pupil_interp']

Use cubic interpolation with wider margin:

>>> data.interpolate_intervals(blinks, method="cubic", margin=(-50, 50))

pupil_blinks_detect(eyes=[], min_duration=20, blink_val=0, winsize=11, vel_onset=-5.0, vel_offset=5.0, vel_onset_min_duration=5.0, vel_offset_min_duration=5.0, max_duration=1000, strategies=['zero', 'velocity'], apply_mask=False, ignore_existing_mask=False, inplace=None)[source]#

Detect blinks in the pupillary signal using several strategies. First, blinks are detected as consecutive sequence of blink_val (f.eks., 0 or NaN). Second, blinks are defined as everything between two crossings of the velocity profile (from negative to positive).

Detected blinks are always stored in the object (retrieve them with get_blinks()). When apply_mask=True, the blinks are also applied as masks to the data. When apply_mask=False (default), the detected blinks are returned as Intervals objects.

Finally, detected blinks have to be at least min_duration ms.

Parameters:

  • eyes (list) – list of eyes to process; if empty, all available eyes are processed

  • min_duration (float) – minimum duration (in ms, or with units) for a sequence of missing numbers to be treated as blink

  • blink_val (float) – “missing value” code for the “zero” strategy. Missing samples (NaN) are always detected; samples equal to blink_val (default 0) are detected in addition. Use np.nan to detect only NaN (e.g., for baseline-corrected data where 0 is a valid value). The “zero” strategy always uses the raw data, so regions masked for other reasons are not detected as blinks.

  • winsize (float) – window-size for Savitzky-Golay velocity estimation (in ms, or with units)

  • vel_onset (float or str) –

    velocity threshold to detect blink onset (negative value).

    • If float: threshold in pupil-units per millisecond (e.g., -5.0)

    • If str: percentile of velocity distribution (e.g., “5%” for bottom 5%)

  • vel_offset (float or str) –

    velocity threshold to detect blink offset (positive value).

    • If float: threshold in pupil-units per millisecond (e.g., 5.0)

    • If str: percentile of velocity distribution (e.g., “95%” for top 5%)

  • vel_onset_min_duration (float) – minimum duration (in ms, or with units) that velocity must exceed threshold to detect as onset (to avoid noise-induced false detections)

  • vel_offset_min_duration (float) – minimum duration (in ms, or with units) that velocity must exceed threshold to detect as offset (to avoid noise-induced false detections)

  • max_duration (float) – maximum duration (in ms, or with units) of a blink detected by the “velocity” strategy; an onset without an offset within this time is dropped. None means no limit. Does not apply to the “zero” strategy.

  • strategies (list) – list of strategies to use; so far, use a list containing any combination of “zero” and “velocity”

  • apply_mask (bool) – if True, apply detected blinks as masks to the data and return the object if False (default), return detected blinks as Intervals (or dict of Intervals)

  • ignore_existing_mask (bool) – if True, use raw data ignoring existing masks if False (default), only detect blinks in non-masked data (already masked regions are skipped)

  • inplace (bool or None) – if True, make change in-place and return the object if False, make and return copy before making changes if None, use the object-level setting

Return type:

PupilData or Intervals or dict

Returns:

If apply_mask=True: returns the object (for chaining) If apply_mask=False and single eye: returns Intervals object If apply_mask=False and multiple eyes: returns dict of Intervals objects (keys like "left_pupil")

pupil_blinks_interpolate(eyes=[], store_as='pupil', method='mahot', winsize=25, vel_onset=-5.0, vel_offset=5.0, margin=(10, 30), blinkwindow=500, interp_type='cubic', inplace=None)[source]#

Interpolating blinks in the pupillary signal.

Implements the blink-interpolation method by Mahot (2013).

Mahot, 2013: https://figshare.com/articles/A_simple_way_to_reconstruct_pupil_size_during_eye_blinks/688001.

The blinks to interpolate are taken from the blinks stored in the object, so blinks have to be detected first (e.g., using pupil_blinks_detect()). The on- and offsets of each blink are refined using the velocity profile before interpolating. Blinks that are so close that the anchor points of one fall into the other are merged and interpolated together. Interpolated samples remain masked; the interpolated blinks can be retrieved with get_interpolated_blinks().

This procedure relies heavily on eye-balling (reconstructing visually convincing signal), so it can help to inspect the result visually (e.g., using plot_blinks()) to set good parameter values for winsize, vel_onset, vel_offset and margin (see paper linked above).

Parameters:

  • eyes (str | list) – str or list of eyes to process; if empty, all available eyes are processed

  • store_as (str) – how to store the interpolated data; either “pupil” (default) which replaces the original pupil data or a string that will be used as the new variable name in the data (e.g., “pupilinterp”)

  • method (str) – method to use; so far, only “mahot” is implemented

  • winsize (float) – size of the Savitzky-Golay window (in ms, or with units)

  • vel_onset (float or str) –

    velocity threshold to detect blink onset (negative value).

    • If float: threshold in pupil-units per millisecond (e.g., -5.0)

    • If str: percentile of velocity distribution (e.g., “5%” for bottom 5%)

  • vel_offset (float or str) –

    velocity threshold to detect blink offset (positive value).

    • If float: threshold in pupil-units per millisecond (e.g., 5.0)

    • If str: percentile of velocity distribution (e.g., “95%” for top 5%)

  • margin (Tuple[float, float]) – margin that is subtracted/added to onset and offset (in ms, or with units, e.g. (10, 30) * u.ms)

  • blinkwindow (float) – how much time before and after each blink to include (in ms, or with units)

  • interp_type (str) – type of interpolation accepted by scipy.interpolate.interp1d()

  • inplace (bool or None) – if True, make change in-place and return the object if False, make and return copy before making changes if None, use the object-level setting

Return type:

PupilData

the object with the interpolated pupil data

pupil_merge_eyes(method='local_offset', lowpass_cutoff=0.2, max_iter=10, keep_eyes=True, inplace=None)[source]#

Merge pupil data from both eyes into a single “merged” variable.

This method combines left and right pupil signals, handling missing data (masked values) intelligently. Where both eyes are valid, the signals are averaged to reduce noise. Where only one eye is valid, that eye’s data is used (with offset correction if applicable).

Parameters:

  • method (str) –

    Method for merging the two eyes. Options:

    • ”local_offset” (default): Compute a slowly-varying offset between eyes using lowpass filtering. This handles drift over the session. The right eye is shifted to match the left eye’s level before merging.

    • ”offset”: Use a single global offset (mean difference) computed over the entire signal where both eyes are valid.

    • ”both_available”: Only use data where both eyes are valid (take mean). Timepoints where only one eye is valid remain masked.

    # TODO: Implement “signal_quality” method that weights eyes by their # local signal quality (SNR), giving more weight to the cleaner eye.

  • lowpass_cutoff (float) – Cutoff frequency (Hz) for the lowpass filter used in “local_offset” method. Lower values produce a more stable offset that only tracks very slow drift. Default is 0.2 Hz (~5 second time constant).

  • max_iter (int) – Maximum iterations for iterative lowpass filtering in “local_offset” method. Default is 10.

  • keep_eyes (bool) – If True (default), keep the original left/right pupil data. If False, remove the original eye data after merging.

  • inplace (bool | None) – If True, modify in-place. If False, return a copy. If None, use the object’s default setting.

Return type:

PupilData

Returns:

The object with merged pupil data stored as “merged_pupil”.

Raises:

ValueError – If only one eye is available (nothing to merge). If an unknown method is specified.

See also

merge_eyes

Generic merge method in GenericEyeData (masks if all eyes invalid)

pypillometry.signal.pupil.pupil_eye_offset

Compute local offset between eyes

Notes

The merged signal is stored as “merged_pupil” and can be accessed via data[“merged”, “pupil”] or data[“merged_pupil”].

The mask for the merged signal reflects which timepoints have valid data: - For “local_offset” and “offset”: masked only where BOTH eyes are masked - For “both_available”: masked where EITHER eye is masked Masked samples still hold the merged stored values (e.g., interpolated blinks), computed as for valid samples (NaN only if both eyes are NaN).

The “local_offset” method is recommended for most use cases as it: 1. Uses all available data (doesn’t discard single-eye timepoints) 2. Handles session-long drift in the inter-ocular difference 3. Produces smooth transitions at boundaries between single/both-eye regions

Examples

>>> # Default: local offset correction
>>> data.pupil_merge_eyes()
>>> merged = data["merged", "pupil"]

>>> # Use global offset (simpler, assumes no drift)
>>> data.pupil_merge_eyes(method="offset")

>>> # Only use timepoints where both eyes are valid
>>> data.pupil_merge_eyes(method="both_available")

>>> # Remove original eye data after merging
>>> data.pupil_merge_eyes(keep_eyes=False)
