Example datasets included in pypillometry#

pypillometry comes with a set of example datasets so that you can start trying out the package right away.

Small datasets are included in the package itself; larger ones are downloaded from OSF the first time they are requested and stored in a cache directory (~/.cache/pypillometry by default), so later calls do not download them again.

[1]:

import pypillometry as pp

You can get an overview of all available datasets with get_available_datasets():

[2]:

pp.get_available_datasets()

[2]:

Using the identifier in the first column, you can load a dataset with get_example_data(). The result is a regular EyeData object:

[3]:

d = pp.get_example_data("rlmw_002_short")

The full-length version ("rlmw_002", about 20 minutes) is downloaded from OSF on first use. If you want to store downloads somewhere else than in the default cache directory, use the cache_dir= argument:

d = pp.get_example_data("rlmw_002", cache_dir="example_data")
