Summarizing pupillometric data#

pypillometry summarizes a dataset at several levels:

  • one dataset: its contents (print(d), summary()), the quality of the data (quality_report()) and how much of it is masked, and why (layer_stats())

  • several datasets: the same summaries as one table with a row per dataset, e.g., to find participants with poor data

  • trials: one value per event or trial (stat_per_event()), together with the events and their metadata

Many of these results are dicts that are displayed as a table: per channel (e.g., layer_stats(): channel -> layer -> statistics) or with one row per trial (a dict of columns). .to_pandas() converts them to a pandas.DataFrame.

[1]:

import pypillometry as pp
from pypillometry import u
import pandas as pd

pp.logging_set_level("WARNING")

After the interpolation, the pupil channels have no unusable samples left (masked: 0 stretches), because interpolated samples are usable; the gaze is still masked during blinks and off the screen.

blink_stats() is a shortcut for the blink rows. Durations of the recording are given by get_duration() and, if periods are excluded (e.g., breaks), excluded_duration():

Trials#

stat_per_event() computes one value per event, e.g., the mean pupil size in the second after each stimulus. Combined with the events and their metadata (see Event metadata), this gives a table with one row per trial, e.g., for a statistical model:

[14]:

d = datasets[0]
epochs = d.get_epochs("S_", (0, 1000) * u.ms)
means = d.stat_per_event(epochs, variables="pupil")
trials = pp.Table({**epochs.events.to_table(), **means})
