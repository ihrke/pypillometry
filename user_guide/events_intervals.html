Events, intervals and segments#

Most experiments send events (triggers) to the eye tracker, e.g., when a stimulus appears or a response is given. Analyses then look at the data in intervals around these events. pypillometry has a class for each step:

        flowchart LR
  E["<b>Events</b><br/>onsets + labels"] -- "get_intervals()" --> I["<b>Intervals</b><br/>(start, end) pairs"]
  I -- "get_segments()" --> S["<b>SegmentedEyeData</b><br/>segments x time"]
  S -- "group_segments()" --> G["<b>GroupLevelSegmentedData</b><br/>participants x time"]
  I -- "stat_per_event()" --> N["one value<br/>per event"]

Events#

get_events() returns the events of a dataset as an Events object, a list of onsets and labels:

events = d.get_events()              # onsets in ms
events = d.get_events(units="sec")   # onsets in seconds
events.filter("stim")                # labels containing "stim"
events.filter(lambda lab: lab.endswith("_1"))
events.filter((60, 120))             # onsets between 60 and 120 s
events[:10]                          # the first ten events

filter() and indexing return new Events. You can store changed events in the dataset with set_events(), e.g., to remove test trials or to rename labels.

Tutorial: Events.

Intervals#

An Intervals object is a list of (start, end) pairs, together with their units and, where applicable, the events they belong to. Intervals come from several places:

Source

Example

windows around events

d.get_intervals("stim", (-200, 1000) * u.ms)

spans between two events

d.get_intervals(("trial_start", "response"), (0, 0))

detected blinks

d.get_blinks("left", "pupil")

other detection methods

d.mask_offscreen_coords(apply_mask=False)

masked samples

d.mask_as_intervals("left", "pupil")

your own

pp.Intervals([(0, 100), (200, 300)] * u.ms)

Intervals can be converted to other units (to_units()), filtered (filter()), padded (pad()), merged when they overlap (merge()), combined (+, merge_intervals()), subtracted (-), summarized (stats(), as_pandas()) and plotted (plot()).

Many methods of the data objects take intervals as input:

GenericEyeData.get_segments

Extract segments from data using intervals.

GenericEyeData.stat_per_event

Return result of applying a statistical function to data in a given interval relative to event-onsets.

GenericEyeData.mask_intervals

Apply Intervals as masks to selected data.

GenericEyeData.interpolate_intervals

Interpolate data within specified intervals.

PupilPlotter.plot_intervals

Plotting data around intervals.

Tutorial: Intervals.

Segments and event-related pupil dilation#

get_segments() cuts the data of one variable in each interval and returns a SegmentedEyeData object (a matrix of segments × time points). Averaged over segments, this is the event-related pupil dilation (ERPD):

intervals = d.get_intervals("stim", (-200, 1000) * u.ms)
erpd = d.get_segments(intervals, "left_pupil", name="stimulus")
erpd = erpd.baseline_correct((-200, 0))   # subtract the pre-stimulus mean
erpd.plot()

group_segments() averages the ERPDs of several participants into a GroupLevelSegmentedData object, which can be plotted the same way. Both can be saved with write_file().

For statistical models of trial-by-trial data, it is often easier to work with one number per trial. stat_per_event() applies a function (by default the mean) to each interval:

peak = d.stat_per_event(interval=(500, 1500) * u.ms, event_select="stim",
                        variables="pupil", statfct=np.max)
